# Fictional demo identities

These local SVG illustrations represent fictional mentors and startups. They are
sample artwork, not photographs or verified organizations. Elena Rossi and the
startups without a logo deliberately use the shared default avatar, so the demo
shows both cases. Every file is served locally; no remote image service,
tracking request, or image upload is required.

The people (`amara`, `david`, `isabel`, `kai`, `lina`, `maria`, `noah`, `priya`,
`rafael`, `sofia`) were generated with [DiceBear](https://www.dicebear.com/)
using the “Avataaars” style by Pablo Stanley
([avataaars.com](https://avataaars.com/), free for personal and commercial
use). Each file keeps its license metadata. `maria` and `david` also appear on
the founder and mentor role-preview accounts. The startup logos are original
artwork.
