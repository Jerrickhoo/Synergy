# Synergy prototype review and delivery

Reviewed on October 19, 2026. This is a local React/Vite prototype, not a production service.

## Usability review — October 19, 2026

This pass builds on the existing restrained teal interface. The main issues were small secondary text, ongoing work appearing after recommendations, excessive mobile header/filter space, and narrow match descriptions on phones.

- **Hierarchy:** moved collaborations, scheduled sessions, and recent activity ahead of recommendations. The mobile workspace summary now shares one row, with counts aligned at the top.
- **Readability:** standardized secondary type at 13px, enlarged match descriptions and small action buttons, and retained visible labels in the tablet navigation rail.
- **Discovery:** kept search and type visible, moved detailed criteria into a labeled disclosure, showed the number of active detailed filters, and added an always-available reset whenever criteria are active. Result counts announce changes. Empty saved lists and filtered-out saved matches now give different guidance.
- **Mobile:** moved global search behind an accessible button with focus management and Escape dismissal. Match descriptions and actions use the full row; buttons stay aligned on narrow phones. Mobile search and filter inputs use 16px text to avoid focus zoom.
- **Forms and feedback:** added the demo password requirements beside the password field. Completed milestones and rooms use green, progress counts and target dates use neutral badges, and waiting/dispute states retain their distinct colors. The room stage exposes its current step to assistive technology. Existing inline errors, loading feedback, confirmations, and business rules remain in place.

Validation: 8 unit tests and 16 browser tests pass, including a new mobile search/filter recovery flow. Production build and formatting checks pass. Responsive checks cover 320, 390, 768, 1024, and 1440px. The [current review gallery](artifacts/ui-review/index.html) contains desktop, tablet, and phone captures of authentication, both role dashboards, discovery, empty results, rooms, terms, milestones, chat, profiles, and validation feedback. No horizontal page overflow or browser exceptions were observed in the capture run. Browser checks use Chromium; this remains the existing in-memory prototype.

## Earlier design refinement

The initial reference-led redesign below was subsequently refined into a quieter interface for founders and mentors comparing collaborators and managing shared work. The refinement preserves the existing text, records, routes, controls, validation, and business logic.

- Removed the mountain illustration, sparkle decorations, background rings, all gradients, header blur/transparency, page entrance animation, and surface shadows. Small overlay shadows remain only to distinguish floating controls from the page below.
- Replaced the dashboard's nested startup cards with comparison rows; workspace counts now share a divided summary strip. Discovery results and rooms use flat lists. Form groups retain restrained borders where they help organize a task.
- Reduced corner radii, enlarged small secondary text, simplified avatar colors, and limited the palette to teal, neutrals, brand accents, and meaningful status colors.
- Retained the Synergy mark, initials, navigation icons, bookmark/notification controls, rating stars, progress indicators, and confirmation checks because they identify people, actions, or state.
- Applied the same treatment to sign-in, signup, onboarding, profiles, waiting introductions, and collaboration rooms, with stacked rows and accessible navigation on phones.

Verification: all 8 unit tests and 15 browser tests passed after the presentation changes; build and formatting checks passed. A final pass captured 43 desktop, tablet, mobile, and onboarding views with no observed horizontal overflow or browser errors. Current screenshots and comparison captures are in the [design refinement gallery](artifacts/refinement/index.html). The original design audit and roadmap follow as the implementation history.

## Current condition

Synergy introduces complementary startups and mentors and gives them a shared collaboration workflow: proposed terms, mutual milestone confirmations, evidence descriptions, chat, and local reviews. The existing React pages use a context/Immer reducer. `src/data/model.js` supplies all sample profiles, rooms, and history; no backend requests or real accounts exist.

The existing build and eight browser tests passed before changes after installing the missing Playwright Chromium prerequisite. The review also found behavior those tests did not cover, including hash navigation establishing a demo session and launching an incomplete, disputed room.

## Implementation boundaries

- No new packages, backend APIs, credential storage, or browser persistence. Existing React/Vite/Immer architecture remains.
- `src/state/routes.js` parses and serializes hashes. Existing `#/` and `#/login` remain; Matches, Waiting, Rooms, Profile, signup, onboarding, match IDs, room IDs, and reviews have explicit addresses. Generated rooms expire on refresh with the in-memory session.
- `src/data/selectors.js` shares profile completeness, active room counts, progress, launch eligibility, and scheduled-session presentation. Schedules store `{ date, time, timeZone }` using the device's local timezone.
- Unresolved disputes block launch. Real dispute resolution remains unavailable, and the UI explains this limit.
- New components separate branding, dashboard cards/headers, profile stats, and form error feedback. The stylesheet replaces the accumulated override cascade.
- Static sample matching scores are illustrative and do not change after profile editing. Sample history does not aggregate local demo reviews.
- Supplied reference and supporting original Markdown/PDF/PNG files remain unchanged.
