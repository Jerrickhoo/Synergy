`Overlay` supports initial focus and busy dismissal guards. The drawer and dialogs share a counted scroll lock, so handing off from mobile navigation to sign-out confirmation does not unlock a live modal or leave scrolling blocked afterward. API enforcement for passwords, session ownership, visibility, deletion/anonymization and room permissions is unchanged.

## Verification

- Final repository formatting, all **69 unit tests**, production build and `git diff --check` passed.
- Targeted browser checks passed for hidden-select required validation/error focus, failed-save selection retention, Settings role/draft restoration, canceled sign-out and offline confirmation, account deletion validation/retry, the preview's viewport bounds/overflow and a full mentorship journey with custom controls.
- Manual Chromium checks measured the preview below the header at 1440, 1024, 768, 390 and 360px, plus 200% CSS layout scaling. Screenshots were captured after the entrance animation settled. This is a layout-scaling/reflow check, not a claim about a particular browser's zoom shortcut.
- Axe WCAG A/AA checks reported no violations on Profile, expanded community forms, Settings, pause/deletion confirmations, the settled notification preview and sign-out confirmation. A manual screen-reader session was not performed.
- A failed pause request left its dialog actionable; retry succeeded and discovery could resume. An expired session dismissed an already-open voluntary sign-out dialog and returned to login without a second prompt. The normal browser suite separately covers password/prototype modes, wrong password, invalid typed DELETE and account deletion.
- The final fresh full browser run passed **all 101 scenarios** across Chromium, Firefox, WebKit and the prototype project. It includes both complete mentorship initiation directions, blind review release, account protections, read-state persistence and all new C–D regression checks. The first integration pass identified native-select test assertions and shared moderation-fixture pollution; these were corrected before the clean final run. Source and test changes were frozen for that final run.
- The completion indicator was also checked with fictional 0%, 17% and 100% profiles for both roles, with exactly one progressbar and appropriate missing-field guidance. Backdrop cancellation preserved the signed-in session. These response-only fixtures did not alter saved profile data.

Local scripts and screenshots are in `output/playwright/polish-cd/` and remain ignored, following the earlier review convention. Tracked reports retain methods, results and evidence links. Existing working data and uploads were not removed.
