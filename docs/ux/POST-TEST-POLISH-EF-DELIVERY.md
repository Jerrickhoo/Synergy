Review date: October 30, 2026. Scope: repository cleanup and integrated verification of the [post-test polish roadmap](POST-TEST-POLISH-ROADMAP.md), following the [A–B](POST-TEST-POLISH-DELIVERY.md) and [C–D](POST-TEST-POLISH-CD-DELIVERY.md) deliveries.

## Phase E: repository cleanup

Ten root documents/reference assets were moved into `docs/product/`, `docs/operations/`, `docs/architecture/`, `docs/archive/` and `docs/ux/`. The [documentation index](../README.md) makes current instructions and historical records distinguishable. The course PDF and flow diagram contain unique material and were retained byte-for-byte. No component, asset, dependency, lockfile, local database or environment file was discarded.

The [cleanup manifest](../maintenance/CLEANUP-MANIFEST.md) records every old/new path, reason, inbound-reference check, CSS removal, retention decision and restoration method. A pre-edit local source archive and SHA-256 inventory protect the existing uncommitted work. All **164 incoming source/reference files** remain at their original or documented moved path, with **zero unexpected modifications** outside the E–F allowlist. Binary hashes match their incoming values. Working accounts, uploads, backups and earlier review evidence were excluded from cleanup.

Removed 17 superseded native-dropdown CSS blocks and native-only branches of two selector lists after confirming that the only `<select>` in JSX is the hidden backing control in `SelectField`. Visible custom controls, form serialization/reset/validation and base form resets remain. Notification rules had already been consolidated in C and were retained. [Source/style ownership](../maintenance/SOURCE-LAYOUT.md) documents the deliberate seven-stylesheet import order and ownership of hover, spacing, preview and dropdown rules.

All move-dependent Markdown links and npm formatting paths were updated. `scripts/check-references.js`, exposed as `npm run check:references`, checks relative documentation and HTML reference paths, counts optional ignored screenshot links separately and fails on missing checkout dependencies. CI now runs it. Public brand/demo assets, source imports and Render/npm commands retain their existing paths.
