## Reference scenarios

Complete, validated viewer inputs live in `demoViewerScenarios` in [server/demo-directory.js](../../server/demo-directory.js). They are test/reference profiles, not extra seeded accounts or hardcoded scores. To reproduce manually, sign in with the indicated Prototype role, edit the profile, and copy the corresponding fields, including goals and engagement preference. The ordinary prototype founder, whose profile has no explicit goals/preference yet, receives eight suggestions. The reference founder adds those optional fields and receives nine. Additional real profiles, edited fixtures, blocked/hidden accounts, active rooms or customized matching weights can change these counts. Suggestions retain the 30% threshold, existing-room exclusion and 12-person cap. Browse all retains eligible low/zero-fit profiles and paginates by 12. Saved can include weak/zero-fit candidates.

## Safe fixture refresh

Demo directory version 2 uses stable `demo-sample-*` account IDs. New fixtures are inserted only in demo mode. Existing unversioned fixtures are compared with the exact legacy name/profile snapshot; versioned fixtures are compared with their stored baseline. Only unchanged identities receive a newer profile and image reference. Changed names, biographies, additional profile fields or other profile edits cause that fixture to be left intact.

Refresh preserves account settings and all shared-work references, including saved profiles, pending introductions and rooms. Repeated startup is idempotent. No working database reset or ID replacement is required. Restart an already-running demo server to load new backend fixtures. Non-demo workspaces do not seed or refresh them; ordinary accounts do not discover demo samples.

The artwork is original local vector illustration. It requires no remote image service. Uploading personal avatars remains a separate extension.
