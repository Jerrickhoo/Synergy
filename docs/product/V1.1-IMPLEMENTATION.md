## Remaining work and reasons

- P2 still needs a Xendit xenPlatform or PayMongo marketplace adapter. This workspace has neither provider credentials nor an agreed marketplace account. The current adapter implements simulation.
- Provider-hosted KYC, sandbox signature verification and live GCash/card transactions require the selected provider account and sandbox.
- Daily reconciliation and discrepancy alerts still need the provider transaction and payout reports.
- Published payment terms, refund policy acceptance and tax receipt wording require the roadmap legal and accounting reviews. The downloadable simulated receipt demonstrates the payment record.
- The four-week metrics gate and Brevo staging delivery remain release requirements. Tests cover local payment and notification paths.

## Run and verify

1. Run npm install, then npm run dev.
2. For separate accounts, set SYNERGY_DEMO_MODE=false. Configure a moderator through SYNERGY_ADMIN_EMAILS and approve the mentor.
3. Accept guidelines version 2. In Settings, complete simulated payout setup, offer a format and save its price.
4. As a founder, request that format. Accept as the mentor, then use checkout as the founder.
5. Choose simulated success, failure or expiry. No real funds move.
6. Run npm run test:unit, npx playwright test tests/mentor-payments.spec.js, npm run build, npm run check:format and npm run check:references.
7. Set PAYMENTS_WEBHOOK_SECRET for callbacks. The simulated webhook expects x-payment-signature, the lowercase hexadecimal HMAC-SHA256 of the exact JSON body. Its body contains id, providerRef and result, with success, failure or expiry.

## Verification results

The final unit suite passes 190 tests, including 32 payment tests. Build, formatting and reference checks pass. The 175-case browser run passed 172 cases and found two admin form-label failures and one WebKit timeout. After fixes, the 24-case affected-suite rerun passed 23 cases and exposed another screenshot timeout. The final WebKit rerun passed all three selected cases, covering the paid journey and both tests with extended screenshot time limits. All observed browser failures have been resolved. A complete 175-case run on the final tree has not been repeated.
